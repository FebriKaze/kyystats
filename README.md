# KyyStats - Data Analysis Portfolio 📊

Welcome to my personal data analysis portfolio! This project showcases my work as a Data Storytelling Specialist, focusing on turning raw data into actionable business growth.

## 🚀 Overview

**KyyStats** is a modern, high-performance web application designed to present data analysis projects, impact metrics, and technical case studies in a visually compelling way. I specialize in descriptive analytics and predictive modeling to help high-growth companies optimize logistics, reduce churn, and scale operations with precision.

## ✨ Key Features

- **Interactive Portfolio:** A beautiful grid of my latest data projects.
- **Case Study Deep-Dives:** Detailed walkthroughs of analytical methodologies and outcomes.
- **Impact Snapshot:** Real-time (or near real-time) visualizations of my professional impact metrics.
- **Dark & Light Mode:** Optimized for readability in any environment.
- **Responsive Design:** Seamless experience across mobile, tablet, and desktop.

## 🛠️ Tech Stack

- **Frontend:** [React](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Build Tool:** [Vite](https://vitejs.dev/)

## ⚙️ Getting Started

To run this portfolio locally, follow these steps:

1.  **Clone the repository:**

    ```bash
    git clone https://github.com/FebriKaze/kyy-stats.git
    cd kyystats
    ```

2.  **Install dependencies:**

    ```bash
    npm install
    ```

3.  **Set up environment variables:**
    - Create a `.env.local` file (if not already present).
    - Add your `GEMINI_API_KEY` (if using AI features):
      ```env
      GEMINI_API_KEY=your_api_key_here
      ```

4.  **Run the development server:**
    ```bash
    npm run dev
    ```
    View the app at `http://localhost:3000`.
